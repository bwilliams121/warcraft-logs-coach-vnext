## Raw deaths (no DEATHS coverage granted)

Since M11-F the capability registry records DEATHS as OBSERVABLE for POSITIVE
death events only, citing segment `seg-0-45` of this fixture. These segments
still grant no DEATHS coverage, so the composed fight answers
`DEATH_EVENT_RETRIEVAL_NOT_ESTABLISHED`. The text below records the E2.1
position when the fixture was committed.

Four raw `death` events are retained. Each has target 45 (Blood Beast
instances 1–4) and source −1. None carries `killerID` or
`killingAbilityGameID`, and that absence is preserved as-is.

Deaths whose victim is outside the scope are not retained. This includes the
one death whose `killerID` is in scope.

No death-completeness claim is made. Tests assert raw facts only.

## M1 empirical evidence (NOT_YET_PROVEN)

The full capture was examined offline (`.probe/m11e2/overkill.cjs`):

- 48 events carry `overkill`.
- Every one has a target snapshot with `hitPoints` 0.
- In all 48, raw `amount` equals the target's last observed pre-hit
  `hitPoints`. `amount` therefore did **not** include the overkill.
- 45 of the target instances have a `death` event.
- No event combines a positive `absorbed` with `overkill`.

This is consistent with "amount excludes overkill", but it is one report and
not an official statement, so M1 stays NOT_YET_PROVEN. No
`OBSERVED_EFFECTIVE_DAMAGE_SUM` exists.

The fixture keeps the focus's one overkill blow: at 7,555,518, `amount` is
82,987 and `overkill` is 116,341. Raw fields stay separate.
