# Warcraft Logs Coach vNext

A clean rebuild of the Warcraft Logs coaching analyzer.

## Goals

- Read Warcraft Logs reports
- Normalize combat data into a reliable internal model
- Analyze rotation, resources, cooldowns, defensives, deaths, talents, and gear
- Keep observed facts separate from inferred state and coaching
- Fail closed when required data is unknown
- Use regression tests to prevent previously fixed bugs from returning
